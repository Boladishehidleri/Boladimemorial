# Boladi — Şəhidlər Memorial Stendi

Bu qovluq GitHub Pages üçün hazır statik saytdır.

## GitHub Pages-də yerləşdirmə

1. GitHub-da yeni repository yaradın, məsələn: `boladi-memorial`
2. Bu qovluqdakı bütün fayl və qovluqları repository-nin əsas hissəsinə yükləyin.
3. Repository → **Settings** → **Pages** bölməsinə keçin.
4. **Deploy from a branch** seçin.
5. Branch: `main`, folder: `/ (root)` seçin və **Save** edin.
6. Bir neçə dəqiqədən sonra GitHub sizə saytın ünvanını verəcək.

Saytın ünvanı təxminən belə olacaq:
`https://SIZIN-GITHUB-ADINIZ.github.io/boladi-memorial/`

## Blogger-ə yerləşdirmə

Blogger-də yeni səhifə yaradıb HTML görünüşündə aşağıdakı iframe kodunu yerləşdirə bilərsiniz:

```html
<div style="width:100%; max-width:1600px; margin:0 auto;">
  <iframe
    src="https://SIZIN-GITHUB-ADINIZ.github.io/boladi-memorial/"
    style="width:100%; height:900px; border:0; display:block;"
    loading="lazy"
    allow="autoplay">
  </iframe>
</div>
```

`SIZIN-GITHUB-ADINIZ` hissəsini öz GitHub istifadəçi adınızla əvəz edin.

Qeyd: Saytın özü ayrıca GitHub Pages-də işləyir; Blogger isə onu səhifənin içində göstərir.
